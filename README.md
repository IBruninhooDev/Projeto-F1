# 🏎️ F1 DEV

Site moderno inspirado na Fórmula 1 desenvolvido com HTML, CSS e JavaScript puro.

O projeto possui design futurista, animações suaves, efeitos 3D, menu responsivo, cards interativos e visual inspirado nas equipes da F1.

---

# 🚀 Demonstração

O site apresenta:

- Hero section moderna
- Carro de Fórmula 1 com efeito 3D
- Cards de pilotos
- Cards de carros
- Animações avançadas
- Partículas e efeitos visuais
- Menu hamburguer responsivo
- Layout adaptado para:
  - Desktop
  - Tablet
  - Mobile
